# API料金を抑えるための運用

## 低価格モード
Replay Studio の「アクト設定・発言者とキャストの対応」から以下を選択します。

- **GPT-6 Luna**: 低価格のOpenAI API文章生成。OpenAI APIキーが必要。事前見積りとセッション予算の目安を提供
- **Ollama**: ローカル文章生成。外部AI API請求は0円（PCの電力・計算資源やホスティング費用は別）
- **サーバー共通設定**: これまで通りのAIモデル。料金見積り・予算ガードの対象外

音声認識は従来どおりローカル faster-whisper（sidecar）を選ぶと音声API料金0円です。

## 初期設定
1. 文字起こし: Settings から `Local sidecar (faster-whisper)` を使用
2. 文章生成: Replay Studio の設定で `GPT-6 Luna` を選択（OpenAI APIキー登録が必要）
3. `Luna予算（USD）` を設定（既定は1セッションあたり $0.50）
4. 設定を保存し、「生成料金を見積もる」を押す
5. 最初は一つのシーンだけ生成し、文体・精度を確認してから全シーンを生成

## 料金の算出方法
- Lunaの参考単価: 入力100万トークンあたり $0.10、出力100万トークンあたり $0.50（2026-11-07の公式API料金）
- トークン見積りはUTF-8のバイト数から計算した**概算**です。正確なトークナイズではありません
- 予算ガードは入力のUTF-8バイト数＋余裕分と、1回の最大出力4,000トークンから安全側の**事前予約額**を計算します
- 成功したAPI生成ではレスポンスの使用トークン数をSQLiteへ記録し、次回の予算チェックに反映します
- この上限はOpenAIアカウントの請求上限設定ではありません。実際の請求額、失敗時の課金、税・為替、異なるモデル料金、複数プロセス同時実行を完全には保証しません
- Luna以外の設定を引き継ぐ場合は価格が分からないため、予算ガードを適用しません

## Ollamaを使う場合
別途Ollamaをインストールし、例として `ollama pull qwen2.5:7b` でモデルを取得します。Web設定からそのモデル名を指定します。
DockerからホストのOllamaへアクセスする際は `OLLAMA_URL` の接続先を確認してください。コンテナ内の127.0.0.1はホストPCではありません。
ローカル生成は大きいモデルほどメモリやGPU容量を必要とし、処理速度と文章の質に差があります。

## その他の節約
- 既存の文字起こし訂正とシーン原稿は保存済みです。生成済みのシーンを不用意に再生成しない
- 一括生成は未生成シーンのみ対象。試行錯誤するときは短いシーンで文体を固める
- AIに送る前に必要ないPL雑談などを発言編集から非表示にする（元の文字起こしは保持）
- 大きすぎるシーンは分割し、必要な部分だけ再実行する

公式価格: https://developers.openai.com/api/docs/pricing
