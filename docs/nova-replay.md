# トーキョーN◎VA リプレイ：自分のAIで生成しHTMLで閲覧する

## どのようなツールか
TRPGReplayMakerは、**個人がGitHubから複製し、自分のPCで動かす**録音・文字起こし・リプレイ編集用アプリです。
多人数向けホスティングや課金サービスではありません。Windowsポータブル版では録音・編集データと設定は原則として配布フォルダー内の `user-data` に保存します。Docker版は別途Dockerボリュームを使用します。

## 1. インストール・起動
Windowsでは[Windows版ビルド](https://github.com/inarin14311431/TRPGReplayMaker/actions/workflows/windows-portable.yml)（GitHubログインが必要）からポータブルZIPを取得し、展開フォルダーの `Start-ReplayMaker.bat` をダブルクリックします。タグ付き配布版が公開されている場合はReleasesから取得できます。Docker Desktop・Node.jsの事前インストールは不要です。初回ログイン `admin` / `admin` は必ず変更します。
Discord Bot作成・招待・音声認識・原稿作成までの流れは [初心者向け利用マニュアル](user-manual.md) を参照してください。

## 2. 自分のAI APIキーを設定
1. Web管理画面 `Settings` の生成AIプロバイダー設定で、使いたいAPI（Gemini / OpenAI / OpenRouter / OpenCode）を選びます。
2. 該当プロバイダーのAPIキーを画面で登録します。ローカルOllamaはAPIキー不要ですが、別途インストールと接続設定が必要です。
3. Discordで `/join` → セッション → `/leave` と録音した後、Replay Studioで対象のアクトを開きます。
4. `アクト設定・発言者とキャストの対応` を開き、`文章生成方式` → `自分のAI API・モデルを指定` を選びます。
5. プロバイダーとモデルIDを入力します（例：OpenAI → `gpt-4o-mini`、Gemini → `gemini-2.5-flash`）。入力値はモデルの提供元で利用可能なものを指定してください。
6. `アクト設定を保存` を押し、生成します。設定変更時のキーの入力先はReplay StudioではなくSettingsです。

**費用の注意**：独自プロバイダー・モデルの料金はツールでは計算しません。低価格Lunaのみ事前見積りと推定予算ガードがあります。APIキーのプロバイダーごとに別の請求が発生する場合があります。
Discord音声の認識は別設定です。ローカルfaster-whisperを使えば音声認識のAPI料金はかかりません。

## 3. トーキョーN◎VAの原稿を作る
新しい録音のアクト設定では、システム名が **トーキョーN◎VA** になります。別システムなら編集可能です。
キャスト名、PL名、RLの役割を整理して、スタイル・神業・固有名詞の表記を用語辞書に登録します。
発言編集ではキャスト発言、RL発言、PLのテーブル上の会話、システム処理を区別できます。
シーンごとにAIへ送る際には、RL・キャスト・スタイル・神業・判定を混同せず、ログにない台詞や結果を作らないよう指示します。
この指示はルールブックの代替ではありません。公式ルールの再現や神業の仕様の正しさは、ユーザーが所持する資料で照合してください。

## 3.5 用語集を活用する

Replay Studioの `アクト設定・発言者とキャストの対応` にある `用語集` から、使用プリセットを選べます。
初期値は**自動選択**で、TRPG共通用語とアクトに設定されたゲーム固有の用語を合わせて使用します。
対象はトーキョーN◎VA、クトゥルフ神話TRPG、ダブルクロス The 3rd Edition、ソード・ワールド2.5、ダンジョンズ＆ドラゴンズ（5版系）。
未登録システムでも共通用語を使用できます。固有の名前や読みは `このアクト固有の用語` に追加してください。
例：`烏丸茉莉｜からすま まつり｜キャストの名前`。収録語は画面上で一覧表示できます。
この機能はAI原稿生成時に語句の意味を伝えます。文字起こしへの直接置換は行いません。
詳しくは [共通・システム別用語集](trpg-glossary.md) を参照してください。

## 4. HTMLリプレイを書き出す
Replay Studio上部の `完成版HTML (.html)` から、単体のHTMLファイルを保存できます。
ファイルをダブルクリックすれば、インターネット接続・ホスト・外部CDNなしで読めます。短い見本は [サンプルHTML](../examples/nova-short-replay.html) にあります。
出力内容はAIで編集済みのシーン原稿があればそれを採用し、なければキャスト名・発言種別つきの原会話を使用します。
主な表示要素：アクト名、シーン目次、開始時刻、RL・キャスト発言、本文、モバイル表示、印刷用CSS。
技術的にはセッション内の文字列をHTMLエスケープし、Markdownの見出し・強調・箇条書き・引用のみを安全に変換します。
装飾は独自CSSのみです。立ち絵・公式タロットの自動埋め込み、画像付きキャストカード、音声プレーヤー同梱は現時点ではありません。
Markdown原稿とJSONの元データも引き続きエクスポートできます。

## 5. 公開と著作権
TRPGReplayMakerそのものは既存のParleyソースを基礎に拡張しています。ライセンスについてはリポジトリのLICENSEおよびUPSTREAM.mdを参照してください。
ゲームの名称や用語を表示することと、公式タロット画像・ルールブック本文・イラストを再配布することは別です。
このリポジトリに公式画像・ルール本文を同梱せず、公開するリプレイ・キャスト画像・音声については各利用者が権利や公開条件を確認してください。
各自のAPIキーや録音データを公開GitHubへコミットしないでください。
