# TRPGReplayMaker 使い方ガイド（Windows）

Discordで遊んだ会話を録音して、リプレイをHTMLで保存するアプリです。

**インストールするのは録音用のPC１台だけ。** ほかの参加者は、普段どおりDiscordを使います。

## 1. アプリをダウンロードする

Windows 64ビット版です。GitHubへのログインや、Docker・Node.jsのインストールは不要です。

1. **[Windows版をダウンロード（ZIP）](https://inarin14311431.github.io/TRPGReplayMaker/TRPGReplayMaker-Windows.zip)** をクリックします。保存先を聞かれたら **ダウンロード** フォルダーを選び、**保存** を押します。
2. Windowsのエクスプローラーで **ダウンロード** フォルダーを開きます。**TRPGReplayMaker-Windows.zip** を右クリックして、**すべて展開** → **展開** をクリックします。
3. 展開してできたフォルダーに **Start-ReplayMaker.bat** があれば準備完了です。Windowsの設定によっては **Start-ReplayMaker** と表示されます。

ダウンロードが始まらないときは、ブラウザ右上のダウンロード一覧を開いて、保存中かエラーが出ているかを確認してください。エラーが出ていれば上のリンクを開き直してください。

## 2. アプリを起動する

1. 先ほど展開したフォルダーを開きます。
2. **Start-ReplayMaker.bat** をダブルクリックします。
3. 黒い画面が開き、少しするとブラウザが開きます。ブラウザが開かない場合は、[http://127.0.0.1:3000](http://127.0.0.1:3000) をクリックします。
4. ログイン画面の **ユーザー名** に `admin`、**パスワード** に `admin` と入力します。
5. **ログイン** をクリックします。

### 最初にパスワードを変更する

1. 画面右上の **admin（丸いユーザーアイコン）** をクリックします。
2. **アカウント・ユーザー管理** をクリックします。
3. **自分のパスワード** の **新しいパスワード** に、新しいパスワードを入力します（**8文字以上**）。
4. **新しいパスワード（確認）** に同じパスワードを入力します。
5. **パスワードを変更** をクリックします。

**黒い画面は閉じないでください。** 閉じると録音用Botも止まります。

## 3. Discordの録音用Botを作る（初回だけ）

1. **[ここをクリックしてDiscordのBot作成ページを開く](https://discord.com/developers/applications)**。
2. Discordにログインします。
3. 右上の **New Application** をクリックします。
4. アプリの名前に **TRPGReplayMaker** など好きな名前を入力し、画面の案内に沿って **Create** をクリックします。
5. 左側の **General Information** をクリックします。
6. **Application ID** の横のコピーボタンをクリックします。
7. TRPGReplayMakerの画面に戻り、**アプリケーションID** の欄に貼り付けます。
8. 再びDiscordのページに戻り、左側の **Bot** をクリックします。
9. **Token** の **Reset Token** をクリックし、表示されたトークンをコピーします。Discordから確認操作を求められた場合は、画面に従います。
10. TRPGReplayMakerの画面に戻り、**Discord Botのトークン** の欄に貼り付けます。
11. **保存して接続する** をクリックします。
12. **DiscordサーバーにBotを招待** をクリックします。Discordの画面で、録音したいサーバーを選んで追加を許可します。

サーバーを追加する権限が必要です。Botが画面に出てこない場合は、TRPGReplayMakerの **使い方ガイド → 状態を更新** をクリックしてください。

**重要：** トークンはパスワードと同じです。DiscordのチャットやGitHubには貼り付けないでください。

## 4. 文字起こしを設定する（録音前に必須）

1. TRPGReplayMakerの画面で録音したい**Discordサーバーを選択**します。
2. 画面の **設定** をクリックします。
3. ページを下へスクロールして、**文字起こし** と書かれた枠を探します。
4. **提供元** の欄をクリックして、次のどちらかを選びます。

### A. 手軽に始める：OpenAIを使う（有料）

1. **[ここをクリックしてOpenAIのAPIキーページを開く](https://platform.openai.com/api-keys)**。
2. OpenAIにログインし、**Create new secret key** からAPIキーを作成してコピーします。利用するにはAPI側の支払い設定や利用枠が必要な場合があります。
3. TRPGReplayMakerの **文字起こし → 提供元** で **OpenAI** を選びます。
4. **APIキー** の入力欄へ、コピーしたキーを貼り付けます。
5. **保存** をクリックします。
6. **モデル** の欄で文字起こし用のモデルを選びます。

**OpenAIに音声を送って文字起こしするため、利用料金が発生します。ChatGPT Plusの月額料金には含まれません。**

### B. API料金をかけない：PCで文字起こしする

1. **[ここをクリックしてPython 3.11のダウンロードページを開く](https://www.python.org/downloads/release/python-3119/)**。
2. ページ下部の **Files** までスクロールし、**Windows installer (64-bit)** をクリックします。
3. ダウンロードしたインストーラーを起動します。**Python Launcher** のインストールを有効にして **Install Now** を押します。Python 3.15などがすでに入っていても、3.11を追加できます。
4. TRPGReplayMakerを展開したフォルダーに戻ります。
5. **Setup-Local-Whisper.bat** をダブルクリックします。インストール完了の案内が出るまで画面を閉じないでください。
6. TRPGReplayMakerを一度終了して、**Start-ReplayMaker.bat** で再起動します。
7. **設定 → 文字起こし → 提供元** で **ローカル文字起こし（faster-whisper）** を選びます。
8. 文字起こし用の機能が停止している場合は、表示された **文字起こし機能を起動** をクリックします。

セットアップで「Python 3.11 is required」と出た場合は、Windowsで **コマンド プロンプト** を開き、`py -3.11 --version` と入力してEnterを押します。`Python 3.11.x` と表示されたら、`Setup-Local-Whisper.bat` をもう一度実行します。表示されなければ、上の3.11のインストーラーで追加してください。

こちらは音声認識のAPI料金はかかりませんが、PCによっては文字起こしに長い時間がかかります。

### 固有名詞の誤認識を減らす

**設定 → 文字起こし** で **ローカル文字起こし（faster-whisper）** を選ぶと、**認識のヒント** が表示されます。「新星市」「神業」など、認識してほしい単語を1行に1語ずつ入力し、**認識のヒントを保存** を押します。新しい録音と、録音詳細で **文字起こしをやり直す** を使った処理に反映されます。ヒントは認識を助けるためのもので、表記を必ず置き換える設定ではありません。

## 5. Discordで録音する

1. **参加者全員に録音することを説明し、同意を得ます。**
2. Discordの録音したいボイスチャンネルへ入ります。
3. Discordのテキストチャットに `/trpg-start` と入力し、表示されたコマンドを選んで実行します。
4. Botがボイスチャンネルに入ったことを確認し、セッションを始めます。
5. 終わったらテキストチャットに `/trpg-stop` と入力し、実行します。
6. TRPGReplayMakerの画面に戻り、文字起こしが終わるのを確認します。

**初めて使うときは、1～2分だけ録音して試す**と安心です。文字起こし中は黒い画面を閉じないでください。

## 6. リプレイを完成させる

1. TRPGReplayMakerの左メニューにある **リプレイ作成** をクリックします。
2. 表示された録音一覧から、リプレイにしたいセッションをクリックします。
3. **アクト設定・発言者とキャストの対応** をクリックして開きます。
4. アクト名、キャスト名、PL名を入力します。ゲームは最初から「トーキョーN◎VA」が選ばれています。
5. **用語集** は、まず **自動選択** のままで構いません。
6. AIで文章を作る場合は、**文章生成方式** を選びます。各自のAIを使用する場合は **設定 → 要約** でAPIキーを登録し、ここでAIの種類とモデル名を指定します。
7. **アクト設定を保存** をクリックします。
8. **文字起こし・原文照合** を開き、聞き間違い、名前、発言の種類を直します。複数の発言が1件にまとまっているときは **発言を分割** を押します。分けたい位置でEnterを押し、1行に1件ずつ並べて **○件に分割して保存** を押します。分割後は発言種別や除外を1件ずつ設定できます。録音の原文と音声はそのまま残り、分けた発言は元のDiscordアカウントと時刻を引き継ぎます。
9. **シーン原稿** を開き、シーンごとにAI生成するか、**未生成の全シーンをAI生成** をクリックします。
10. 生成された文章を確認して必要なところを直し、**原稿を保存** をクリックします。
11. 画面上部の **完成版HTML (.html)** をクリックします。完成したリプレイがパソコンに保存されます。

保存したHTMLファイルは、**ダブルクリックするだけでブラウザで読めます。**

**[完成したリプレイの短い見本を見る](../examples/nova-short-replay.html)**

## 7. 使い終わったら

1. 録音や文字起こしが終わっていることを確認します。
2. TRPGReplayMakerの**黒い画面をクリック**します。
3. キーボードの **Ctrl + C** を押して終了します。

録音や設定は、アプリを展開したフォルダー内の **user-data** に保存されています。

**バックアップする場合**は、アプリを終了してから **user-data** をフォルダーごと別の場所へコピーしてください。APIキーや録音内容が入っているため、他人には渡さないでください。

## 文字起こしに失敗したとき

録音詳細に「文字起こしに失敗」と出たときや、リプレイ編集で「0 発言」と表示されるときは、まず **録音一覧** で対象の録音を開きます。文字起こしが処理中なら、発言が表示されるまで待ちます。失敗していたら、次の順に確認してください。

1. 画面上部で録音した **Discordサーバー** を選び、左メニューの **設定 → 文字起こし → 提供元** を開きます。
2. **OpenAI** を選んでいる場合は、すぐ下の **APIキー** が **登録済み** か確認します。未登録ならキーを貼り付けて **保存** を押します。登録済みでも失敗するときは、APIの支払い設定や利用枠、モデルを確認します。APIキーは他人に送らないでください。
3. **ローカル文字起こし（faster-whisper）** を選んでいる場合は、**動作中** になっているか確認します。停止中なら **文字起こし機能を起動** を押します。WindowsのZIP版で未セットアップなら、上の「API料金をかけない：PCで文字起こしする」の手順で準備します。
4. **録音一覧** から元の録音に戻り、**文字起こしをやり直す** をクリックします。元の音声が残っていれば、録り直さずに再試行できます。
5. 発言が表示されたら **リプレイ作成** に進みます。再試行ボタンを押せないときは、録音詳細に表示されている理由を確認してください。元の音声が残っていない場合は、新しく録音してください。

「failed transcription」などのエラーだけでは、原因がローカル機能の停止か、OpenAI側のエラーかは分かりません。再び失敗するときは、選んでいる提供元と画面のエラー文を控えてください。

OllamaをPC上で動かす場合、要約やリプレイ生成にAPI料金はかかりません。音声の文字起こしをAPI料金なしで行うには、ローカル文字起こし（faster-whisper）を選びます。

## 困ったとき

- **ブラウザが開かない**　[http://127.0.0.1:3000](http://127.0.0.1:3000) をクリックする。開かなければ黒い画面のエラーを確認
- **`Start-ReplayMaker.bat` がない**　[ダウンロード手順](#1-アプリをダウンロードする)の手順2で **すべて展開** を選び、展開してできたフォルダーを確認
- **DiscordのBotが入らない**　アプリケーションID・トークン・Discordサーバーの追加権限を確認
- **`/trpg-start` が出ない**　旧版を使っている場合は最新版を起動します。Botがオンラインか、サーバーでコマンドを使う権限があるかも確認します。
- **文字起こしされない**　**設定 → 文字起こし** に戻り、選んだ方式と設定を確認
- **リプレイをHTMLで保存できない**　**リプレイ作成** で録音を開いてから **完成版HTML (.html)** をクリック

**補足：** これはWindows用の実行版です。Discordの長時間録音については十分な実機検証がまだ済んでいません。まず短いテスト録音で確認してください。
