# TRPGReplayMaker 利用マニュアル（Windows／Docker不要）

このマニュアルは、**GitHubから配布ZIPを取得して自分のWindows PCで使う方**を対象にしています。トーキョーN◎VAを既定にしていますが、他のTRPGシステムも使用できます。セッションに参加するPL全員がインストールする必要はありません。**Botを運用する人のPCだけ**にインストールします。

> このアプリは録音、文字起こし、AIによる文章整形、HTML出力を別々に行います。録音は自分のPCで実施し、外部APIを選んだ処理だけが外部サービスに音声または文章を送信します。録音する前に参加者全員の同意を得てください。

## 1. 配布ZIPを入手する

- **Windows 64bitの一般利用者**：[Windows Portable ZIP（GitHub Actions）](https://github.com/inarin14311431/TRPGReplayMaker/actions/workflows/windows-portable.yml)を開き、成功した最新の **main** の実行を選択します。「Artifacts」の **TRPGReplayMaker-Windows-Portable** をダウンロードします。GitHubアカウントでのログインが必要です。
- 取得したファイルを展開すると内部に **TRPGReplayMaker-Windows.zip** があるので、これも展開します。フォルダーに `Start-ReplayMaker.bat` と `runtime\node.exe` があれば配布版です。
- タグ付きの公開版があるときは[Releases](https://github.com/inarin14311431/TRPGReplayMaker/releases)に同じZIPが掲載されます。ただし公開タグが作られていない場合、Releasesにはファイルがありません。
- GitHubトップの「Code → Download ZIP」は**ソースコード**です。配布版とは違い、Node.js 24以上とnpmのインストールが別途必要です。

**Docker Desktop、WSL2、Git、Node.jsの事前インストールは配布版では不要です。** ただしDiscord Botの作成は必要です。配布ZIPはWindows向けで、署名付きインストーラーではありません。入手元がGitHubのリポジトリであることを確認してください。

## 2. 初回起動・ログイン

1. 配布ZIP内のフォルダーを、デスクトップやドキュメントなどの**書き込み可能な場所**へすべて展開します。ZIPファイルを開いたまま直接実行せず、`Program Files`などの保護フォルダーも避けます。
2. `Start-ReplayMaker.bat` をダブルクリックします。コマンド画面とブラウザが開き、通常 `http://127.0.0.1:3000` にアクセスできます。接続できなければ再読み込みし、コマンド画面に表示された実際のポート番号も確認します。
3. 初回アカウントはユーザー名 `admin`／パスワード `admin`。ログイン後、**直ちに自分専用のパスワードへ変更**します。
4. 起動した黒いウィンドウを閉じるとWeb画面とDiscord Botも停止します。セッション中はPCをスリープさせず、ネットワークを維持します。

## 3. Discord Botを登録する（初回だけ）

1. [Discord Developer Portal](https://discord.com/developers/applications)にログインし、**New Application** から自分用のアプリを作成します。
2. **General Information** の **Application ID** をコピーします。
3. **Bot** ページでBot Tokenを取得します。ここで取得する文字列はパスワードと同じ重要情報です。DiscordチャットやGitHubへ貼り付けないでください。
4. TRPGReplayMakerの初期設定画面に **Bot Token** と **Application ID** を貼り付け、**保存して接続する**を押します。
5. アプリケーションIDから生成された **DiscordサーバーにBotを招待** を選び、録音したいDiscordサーバーへBotを追加します（サーバー管理権限が必要）。
6. 画面の **使い方ガイド** に戻り、Botの接続状態とサーバーの認識を確認します。招待後に表示されない場合は **状態を更新** を押します。

## 4. 音声の文字起こし方式を選ぶ（録音前に必須）

録音と文字起こしは別の機能です。**Windowsポータブル版にはPython Whisperを標準同梱していない**ため、どちらかを必ず設定してください。

### 方法A：OpenAI音声認識API（手軽・従量課金）

1. [OpenAI APIキー](https://platform.openai.com/api-keys)を自身のアカウントで発行します。ChatGPTの有料プランとは別契約・別請求です。
2. Web画面の **Settings → Transcription** で **OpenAI (cloud)** を選択します。キーの入力欄が表示されたら保存します。
3. APIキー登録後に音声認識モデルを選びます。モデルごとに対応するレスポンス形式や料金が異なるため、問題があれば `whisper-1` で小さな録音を試します。
4. この方式で文字起こしを行うと、音声データがAPI提供元へ送られ、使用量に応じた料金が発生します。原稿を作るための文章生成AI APIとは別です。

### 方法B：ローカル faster-whisper（API従量課金なし）

1. [Python 3.11](https://www.python.org/downloads/)をWindowsへインストールします（Pythonランチャー `py` が利用できる状態）。
2. 配布フォルダーの **Setup-Local-Whisper.bat** を実行します。追加の音声認識ライブラリをダウンロードします。
3. セッション前にアプリを再起動します。
4. **Settings → Transcription** で **Local sidecar (faster-whisper)** を選びます。必要に応じてモデルを選択します。
5. 初回の音声認識モデル取得にはネット接続が必要です。その後はPCで処理するためAPIの音声認識料金は発生しません。ただしCPU/RAM・電力を使い、長い録音では処理に時間がかかります。

**注意**：どちらも設定せずに録音すると、文字起こしに失敗する場合があります。最初は短い試験録音で確認します。

## 5. 短いテスト録音を行う

1. Discordのボイスチャンネルへ入り、録音することについて参加者全員の同意を取ります。
2. Discordのテキストチャットに `/join` と入力し、BotがVCへ接続することを確認します。
3. 1～2分ほど会話します。複数人の発言を含めると、話者ごとの文字起こしを確認できます。
4. `/leave` で録音を終了します。文字起こし処理が終わるまで起動ウィンドウを閉じないでください。
5. Web画面から録音履歴を開き、テキストが生成されているかを確認します。失敗しているときは設定とログを確認します。

## 6. リプレイを編集・生成する

1. Webの **リプレイ作成（Replay Studio）** から録音を選択します。
2. **アクト設定・発言者とキャストの対応** でタイトル、TRPGシステム名、PLとキャストの対応を入力します。既定値は「トーキョーN◎VA」です。
3. **用語集** で「自動選択」を使うと、TRPG共通用語＋該当ゲームの用語集をAIへの参考として渡せます。キャスト固有名詞は1行1件で追加します。用語集そのものが原文を自動書換えするわけではありません。
4. **文字起こし・原文照合** で原音声を確認し、固有名詞の誤りや発言種別（RL／キャスト／PLなど）を修正します。元の文字起こしは保持されます。
5. 長いセッションはシーンを作成して分割します。**シーン原稿** で個別生成、または未生成シーンの一括AI生成を利用します。
6. AI文章生成の設定では、各自の **OpenAI / Gemini / OpenRouter / OpenCode API** などを選択できます。キーはSettingsに登録し、Replay Studioではプロバイダー・モデルを選びます。ローカルOllamaも選べますが別途インストールが必要です。
7. AI原稿の編集後、**原稿を保存**します。AIが人物名・判定結果を誤認した場合は必ず修正します。

### 完成品の保存

- **完成版HTML (.html)**：単独のファイルとしてブラウザで読めます。N◎VA設定ではサイバーパンク調のレイアウト。
- **原稿 (.md)**：再編集しやすいMarkdown文章。
- **会話ログ (.md)**：時間と発言者を残した記録。
- **編集データ (.json)**：別途バックアップやデータ確認に使うエクスポート。

短い架空アクトの完成例は [『硝子の目撃者』HTMLサンプル](../examples/nova-short-replay.html) にあります。

## 7. 終了・データ保存・更新

- 停止は起動したコマンド画面で **Ctrl+C** です。録音・文字起こし・AI生成中の強制停止は避けてください。
- ポータブル版の設定、APIキー、SQLiteデータベース、録音は配布フォルダー内の **user-data** に入ります。誰かとZIPを共有するときにこのフォルダーを含めないでください。
- 更新するときはアプリを停止し、**user-dataを別の安全な場所へバックアップ**します。新しい配布ZIPを別フォルダーへ展開し、必要に応じてuser-dataを移動します。
- Docker版は録音とDBを**Dockerボリューム**に保存します。ポータブル版とは自動同期せず、既存データの移行には別作業が必要です。
- 起動中にPCがスリープ・再起動すると録音は中断します。未完了音声の復旧機構はありますが、未録音の区間を復元することはできません。

## 8. トラブルシューティング

| 状況 | 確認事項 |
|---|---|
| `node.exe` が見つからない | 配布ZIPでなくソースZIPを取得していないか確認。配布版なら `runtime\node.exe` が同梱されています |
| ブラウザが表示されない | 起動ウィンドウのエラーとポート番号を確認。起動後にブラウザを更新 |
| Discord Botが接続されない | Token/Application ID、招待先サーバー、BotのConnect/Speak権限、ネット接続を確認 |
| `/join` が表示されない | Botがオンラインか、アプリコマンド権限を付与しているか確認 |
| 音声が文字にならない | SettingsのTranscription方式・APIキー・ローカルWhisperの導入状態を確認 |
| OpenAIでエラー | APIキー、利用枠、選択モデル、音声認識の料金・対応フォーマットを確認 |
| ローカルWhisperが使えない | Python 3.11と仮想環境の作成、CPUメモリ、ダウンロードのネット接続を確認 |
| HTMLが保存できない | リプレイ編集画面の完成版HTMLを使い、保存先の書込み権限を確認 |

### 開発者向け・Docker方式

Docker版の起動・停止には **Start-ReplayMaker-Docker.bat / Stop-ReplayMaker-Docker.bat** を使えます。通常のWindows利用者はDockerを入れる必要はありません。GitHubのソースZIPから開発する場合はNode.js 24＋npmを別途用意します。

## 9. 現時点の制約

- Discordの8～12時間連続録音は実機での十分な検証を終えていません。
- Windowsポータブル版は署名付きインストーラーではなく、セキュリティポリシーによって実行が禁止される場合があります。
- **文字起こしAPIも文章生成APIも、選択した提供元の料金・制限が適用**されます。自動予算ガードは全モデル共通ではありません。
- 公式画像やルールブック本文は本アプリの配布物に含みません。
