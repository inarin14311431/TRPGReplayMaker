# TRPGReplayMaker 共通・システム別用語集

## 目的と適用範囲
音声から作った会話ログは、固有名詞・略語・役職名などを誤記しやすいため、リプレイ文章を整えるAIに語彙情報を渡します。
「ゲームの用語の意味の補助説明」であって、正式なルールの説明文や判定結果をAIに作らせるものではありません。

**重要**：この用語集は現在、**文章生成AIのプロンプトにのみ適用**されます。faster-whisperの語彙登録・音声認識の修正、自動的な発言テキストの置換には使用されません。誤認識はReplay Studio内の「文字起こし・原文照合」で修正してください。

収録語の正式表記・読み・短い意味は `src/replay/glossary.js` に定義されています。公式ルールブック文章の転載ではなく、用語の一般的な言い換えによる短い説明です。版や卓ごとのハウスルールを優先してください。

## アクトごとの使い方
1. Replay Studioで録音を開き、`アクト設定・発言者とキャストの対応` を展開します。
2. `TRPGシステム` に遊んだゲーム名を入力します。新規アクトはトーキョーN◎VAです。
3. `用語集` の使用プリセットを選択します。**自動選択**を選ぶと、TRPG共通用語＋該当するシステムの用語が追加されます。
4. `収録済みの用語と説明を見る` から登録内容を確認できます。
5. `このアクト固有の用語・登場人物` 欄にキャスト名・シナリオ固有語・希望の表記などを1行1件で記入します。
6. `アクト設定を保存` をクリックします。以後のAI生成で参考情報として使用します。

## 独自用語の書き方

```text
真白｜ましろ｜キャストの名前
京｜けい｜キャストの名前
神業｜しんぎょう｜TRPGの特殊能力を表す語として用いる
研究棟ルートB｜けんきゅうとうるーとびー｜今回のシナリオの施設名
```

システム固有の語と誤解しそうな名前は、意味や役割まで補足するのが有効です。利用者のゲームにない語句は書かないでください。

## コスト・精度について
- 用語集を追加すると生成AIへ送るトークン数が増え、モデルによっては費用が上がります。
- 共通語とシステム別用語はセットで読み込まれます。無関係なシステムの語を混ぜません。
- 用語集は文脈理解を補助するものなので、AIの誤読や推測を完全に防ぐ保証はありません。
- 固有名詞を正確に直す場合は、音声を聞きながら人間が文字起こしを確認してください。

## 拡張の方法
現在の収録データは `src/replay/glossary.js` の `GLOSSARY_PRESETS` にまとまっています。
他のシステムの追加は同ファイルに `id / label / description / terms` を定義し、 `inferSystemPreset()` にシステム名の対応付けを追加します。
いずれも公式ルール本文・公式イラスト等を同梱せず、権利に配慮してメンテナンスしてください。
