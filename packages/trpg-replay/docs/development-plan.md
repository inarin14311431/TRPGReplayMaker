# TRPGReplayMaker 開発ロードマップ

## Phase 1: Baseline
Parley本体の録音、参加者別PCM、Whisper文字起こし、JSONエクスポートを動作確認。現時点の13時間対応はタイムスタンプと大量行の処理テストに限定され、Discord実機の長時間録音は未検証。

## Phase 2: 長時間録音の信頼性
1. 発話ターン確定ごとにmanifest.jsonlを保存し、時刻・話者ID・ファイル名・検査値を記録。
2. 録音途切れ、Bot再起動、空き容量不足での復旧を検証。
3. トラックごとの文字起こし成功状態を保存し、失敗したトラックだけ再試行可能にする。
4. 生音声をリプレイ照合終了まで保持し、保存期限と削除操作を用意。
5. 録音品質検証のため30分→2時間→8時間→12時間の実機試験。

## Phase 3: リプレイ制作
固有名詞辞書、キャスト名・PL名の対応、GM描写・判定・神業の抽出、シーン編集と原文照合、会話型・小説型・ハイブリッド型の生成。生成内容には出典行を紐付け、捏造を防止する。

## セキュリティ
録音前の参加者同意、Botトークン秘匿、音声保存先保護、Web管理画面の認証とアクセス制限を優先する。
